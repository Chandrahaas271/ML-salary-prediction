Automated Data Cleaning & ETL Pipeline

Step-by-step transformation applied to raw enterprise telemetry data

1
Identifier Column Stripping (`employee_id`)
`employee_id` is a non-predictive tracking hash. Retaining it introduces spurious noise.
df.drop('employee_id', axis=1, inplace=True)
Result: "Dropped employee_id — non-predictive tracking identifier eliminated"
2
Deduplication Engine
Eliminates identical duplicate employee entries that cause artificial sampling bias.
df.drop_duplicates(inplace=True)
Result: "Rows before: 89 | Rows after: 85 (4 duplicate rows purged)"
3
Type Coercion for Performance Score
Casts raw string values and whitespaces to IEEE float64 format, coercing corrupt values to NaN.
df['performance_score'] = pd.to_numeric(df['performance_score'], errors='coerce')
Result: "performance_score converted from object to float64"
4
Robust Median Imputation
Replaces missing values (NaN) with robust non-skewed column medians (Experience: 8.2, Age: 38.0, Rating: 2.8).
df['years_experience'].fillna(df['years_experience'].median(), inplace=True)
Result: "5 experience, 4 age, and 3 performance NaN values successfully imputed"
5
IQR Outlier Filtering
Detects and prunes extreme outlier salaries (₹99,99,999 & ₹88,88,888). Upper bound cutoff: ₹2,05,012.
df = df[(df['monthly_salary'] >= lower) & (df['monthly_salary'] <= upper)]
Result: "Purged 2 extreme corrupt salary outliers exceeding upper bound cutoff"
6
Department One-Hot Encoding (`drop_first=True`)
Converts categorical departments into binary indicators to eliminate dummy variable trap.
df = pd.get_dummies(df, columns=['department'], drop_first=True)
Result: "Department encoded: ['department_HR', 'department_IT', 'department_Marketing']"

# Step 3 — Coerce numeric performance scores
df['performance_score'] = pd.to_numeric(df['performance_score'], errors='coerce')

# Step 4 — Robust median imputation for missing values
for col in ['years_experience', 'age', 'performance_score']:
    df[col].fillna(df[col].median(), inplace=True)

# Step 5 — IQR salary outlier removal
Q1 = df['monthly_salary'].quantile(0.25)
Q3 = df['monthly_salary'].quantile(0.75)
IQR = Q3 - Q1
upper_bound = Q3 + 1.5 * IQR
df = df[df['monthly_salary'] <= upper_bound]

# Step 6 — One-hot encoding
df = pd.get_dummies(df, columns=['department'], drop_first=True)
print("Clean dataset features:", list(df.columns))

Executive Compensation Strategy

Key takeaways derived from model weight vectors for HR & Finance leadership

1. Primary Valuation Drivers

Years of Experience serves as the primary linear driver of salary, yielding approximately ₹4,775 per month for every year of tenure. Performance Appraisal is second, generating ₹6,040 per point rating. Compensation committees should align salary bands around experience tiers while rewarding high performers with merit-based bonuses.

2. Operational Rupee Precision

Achieving an R² score of 92.55% with an average error (MAE) of ₹6,457.40 provides sufficient precision for corporate salary benchmarking, equity auditing, and offer letter generation within an expected 5% variance margin.

3. Model Scope & Architectural Limits

Linear Regression models assume constant variance and independent features. It does not model diminishing marginal returns for executive-level tenure (>20 years) or complex interactions between specific certifications and departmental roles. Higher-order non-linear models (XGBoost / Random Forest) can capture these edge cases.
